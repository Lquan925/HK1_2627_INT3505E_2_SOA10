# Gateway / API Layer

Router cho Chat, Document, Quiz Review, Grade Planning, Comment và Recommendation. auth.py dành cho danh tính/quyền của ứng dụng; schemas.py dành cho validation. API chỉ điều phối service, không chứa SQL hoặc prompt.

Hiện là file khung, chưa triển khai nghiệp vụ. Xem [bảng chia việc](../../../../docs/modules.md) và [kiến trúc](../../../../docs/architecture.md).
